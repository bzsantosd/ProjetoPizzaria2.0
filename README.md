# Pizzaria Bella Pizza - Versão 2.0

Esta é a evolução do projeto original da pizzaria. <br>
Na versão 2.0, o foco foi além da interface institucional, implementando funcionalidades de **autenticação** e **gerenciamento de perfil de usuário**.

---

## ✨ Novidades da Versão 2.0

* **Sistema de Login:** Nova página de acesso (`login.html`) com estilização exclusiva.
* **Área do Usuário:** Painel dedicado ao cliente (`usuario.html`) para gerenciar pedidos e informações.
* **Refatoração de Código:** Separação mais clara entre lógica de autenticação (`usuario.js`) e lógica geral (`script.js`).
* **Design Aprimorado:** Novos arquivos de estilo específicos para cada seção (`login.css`, `usuario.css`).

---

## 🎨 Design e Planejamento

Assim como na primeira versão, este projeto segue as diretrizes de design definidas no **Figma**, garantindo uma identidade visual consistente em todas as novas telas.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estrutura avançada com múltiplas páginas interligadas.
* **CSS3:** Estilização modularizada (arquivos separados para melhor manutenção).
* **JavaScript:** Manipulação de eventos, validação de login e interatividade.
* **Figma:** Prototipagem da interface de usuário (UI).

---

## 📁 Estrutura do Projeto

* `index.html`: Home page da pizzaria.
* `login.html` / `login.css`: Tela e estilo de acesso ao sistema.
* `usuario.html` / `usuario.css` / `usuario.js`: Estrutura, visual e lógica da área logada.
* `estilo.css`: Estilos globais da aplicação.
* `script.js`: Funções gerais do site.

---

## ⚙️ Como executar

1. Clone o repositório.
2. Abra o arquivo `index.html` para navegar pelo site.
3. Teste o fluxo de navegação entre a Home, a tela de Login e a Área do Usuário.
